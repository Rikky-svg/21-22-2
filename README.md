# Учебный проект «Сладкий дом»

## Назначение
Проект предназначен для практических занятий №21–22: технический SEO-аудит, UX-, контентный и комплексный аудит учебного сайта.

## Запуск
1. Распакуйте архив.
2. Откройте папку в Visual Studio Code.
3. Запустите `index.html` в браузере.
4. Для проверки откройте Chrome DevTools → Lighthouse и выберите Mobile, Performance, Accessibility, Best Practices, SEO.

## Важно
Статусы 301, 302, 403 и 500 моделируются в файле `url-map.csv`: их нужно проанализировать и предложить решение. В локальном статическом сайте они не воспроизводятся как реальные серверные ответы.
